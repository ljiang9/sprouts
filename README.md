# sprouts（豆芽棋 · 简化版）

纸上拓扑游戏 Sprouts 的极简实现：纯 Python 标准库，无依赖。

## 玩法

- `n` 个点开局（默认 3），每个点有 3 条"生命"。
- 每步：在**同一区域**内选两点 A、B（可相同，相同即**自环**，需要 2 条生命），
  连一条曲线。A、B 各消耗 1 条生命，曲线上产生一个**新点**（剩余 1 条生命）。
- 曲线把区域分成两个新区：A、B、新点同时属于两个新区（它们在分界线上），
  其余点由**走棋方**划分到两侧。后续走子必须在同一区域内进行。
- 无子可走者负。

## 用法

```bash
python3 -m sprouts                      # 人机交互（需要终端）
python3 -m sprouts --auto                # AI 对 AI 自动演示 10 局
python3 -m sprouts --auto --games 20 --seed 7 --spots 4
```

交互输入格式：`区域 A B`（A==B 为自环），之后按提示输入划分方案。

## 设计取舍（诚实版）

- 这是"生命数 + 区域划分"抽象，**省略了真实 Sprouts 的平面嵌入几何约束**
  （真实规则里曲线不能交叉、区域形状由几何决定）。
- 本实现里走棋方自由选择划分方式——这恰好对应真实 Sprouts 里走棋方选择曲线走向。
- 每步全局生命数严格减 1，对局必在 `3n-1` 步内结束，无需和棋判定。

## AI 说明

贪心 AI：对每个候选（走法，划分）采样，选"困住"最多活点
（使其所在区域无走法）的方案；平局随机打破，`--seed` 可复现。

## 已知局限

- 拓扑是简化的，不是真实平面 Sprouts；结论不可用于真实 Sprouts 定理验证
- AI 只是采样贪心，不做深层搜索；熟悉规则的人类通常能赢
- 文本界面，无图形/存档/悔棋；Python 3.10+，纯标准库
